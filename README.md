# Nutrition Lab

iPhone・PCのブラウザで使う食事記録と栄養学習アプリです。index.htmlにアプリと食品データを内蔵しています。

## データ
文部科学省「日本食品標準成分表（八訂）増補2023年」（2026年3月27日更新）第2章から加工。
https://www.mext.go.jp/a_menu/syokuhinseibun/mext_00001.html
全2,538食品・43成分。成分値は可食部100g当たり。微量・推定・欠測を区別しています。

## 記録の保存
食事記録は利用中のブラウザ内へ保存します。食事記録をGitHubへ送る機能はありません。
端末間の自動同期はありません。「設定・保存」でJSONバックアップを保存・復元できます。
URLやブラウザが変わったときはJSONで記録を移してください。

## iPhone
Safariで公開URLを開いて使います。Safariの共有メニューからホーム画面へ追加できます。
本公開版にはオフライン再起動を保証するService Workerはまだありません。
iPhone実機では未検証です。
